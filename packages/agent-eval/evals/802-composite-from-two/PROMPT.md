Implement the `Testimonial` component for this kickstartDS design system
package.

Its props are already specified in
`src/components/testimonial/testimonial.schema.json` — treat that schema as the
source of truth for the component's API.

A testimonial shows what a customer said, their picture, their name and role,
and the score they gave us. It goes on the marketing pages, several to a row.

Requirements:

- Implement the component under `src/components/testimonial/`.
- Follow this design system's conventions for authoring a component: file
  layout, naming, styling approach, and how a larger component is assembled out
  of the smaller ones the package already has.
- Styling must use the design system's tokens rather than literal values.

Do not modify `testimonial.schema.json`, and leave the rest of the package as
you found it.
