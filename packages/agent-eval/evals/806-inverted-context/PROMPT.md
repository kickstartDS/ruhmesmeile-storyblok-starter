# Task

`Spotlight` came with its own dark mode and it's the wrong one. It flips with
the reader's OS setting, which means it goes dark on a light page and stays
light inside a dark band — the two things it should never do.

Design want it to behave like everything else in the library: when it sits in
a region that has been flipped, it flips with it, and otherwise it doesn't.

Colours are the only thing wrong here. Spacing and type are fine.
